# QA trình duyệt đợt 6 (30/10/2026): CHƯA CHẠY ĐƯỢC

**Lý do:** Chrome mà công cụ `mcp__claude-in-chrome__*` điều khiển không chạy trên máy dev này (không có tiến trình `chrome.exe`),
nên không với tới `localhost`. Backend (`:3000`) và Vite (`127.0.0.1:5173`) đều lên bình thường (curl trả 200), nhưng Chrome báo
`ERR_CONNECTION_REFUSED` ở cả `localhost` và `127.0.0.1` (đã thử 3 lần, cả hai địa chỉ). Theo luật đợt 6, bỏ phần QA trình duyệt và ghi lại ở đây.

Môi trường để người dùng tự QA nhanh:

```
cd Backend  && node scripts/itest-account.js      # in email/mật khẩu manager + member tạm, có sẵn 1 người đã mất (Nguyễn Văn Lâm)
cd Backend  && npm run dev                          # cổng 3000
cd Frontend && npm run dev -- --host 127.0.0.1      # Vite mặc định chỉ nghe IPv6 (::1) trên máy này; Chrome dùng IPv4 nên cần --host
cd Backend  && node scripts/itest-cleanup.js        # dọn xong
```
